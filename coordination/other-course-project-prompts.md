# 另外三门课程项目的启动提示词

下面三段提示词分别复制到对应的 Codex 项目中。三个项目只负责自己的课程内容、前端和标准化交付包；共享服务器、域名、HTTPS、数据库与总入口由 PHY301 总控项目统一集成，避免并行任务互相覆盖。

## 1. PHY408 — Data Intensive Science

```text
你现在负责把这个项目中的 PHY408（Data Intensive Science）全部课程资料，制作成一套“从零起步、可以按顺序无障碍学完”的中文主导、英文术语对照的学习站。

我的情况与目标：我上学期学习基础不牢，许多知识点可能完全陌生。不要假设我已经懂 Python、线性代数、概率统计、数值计算、数据处理或机器学习。目标不是赶工，而是在尽量短的学习时间内获得最高学习效率。你可以花足够时间检查所有课件、作业、讲义、代码、数据集、课程大纲和考试材料，不能漏掉老师要求掌握的内容。

请按以下要求自主完成，不要只给计划：

1. 先做完整资料盘点和覆盖矩阵：逐个文件、逐页课件、逐题作业登记，建立“原材料 -> 知识点 -> 学习节点 -> 练习/考核”的可追溯关系。保留原文件，禁止覆盖或删除。
2. 依据课程材料反向设计前置知识树。至少检查并按需要补齐：Python 基础、NumPy/Pandas/绘图、命令行与文件格式、向量与矩阵、微积分、概率统计、误差与数值稳定性、数据清洗、可视化、回归/分类/降维/聚类、验证与过拟合、可复现科学计算。这里只是候选清单；以项目里的真实资料为准，不可凭空替代老师大纲。
3. 学习顺序必须由浅入深。每个节点都要包含：为什么学、直觉解释、严格定义、符号与单位、最小示例、代码示例、图示、常见误区、与前后节点的连接、检查题、答案与进一步阅读。若某部分很大，做成可展开的子模块，但不能跳过依赖。
4. 把全部英文课件做成中英逐页精讲版：每张原始英文页完整保留，紧随其后插入一页或多页中文忠实翻译、入门解释、公式/代码/图表解读、术语、易错点。优先保留 PPTX，确保原动画、叠加图层、GIF、媒体和讲者备注不丢失；如另导出 PDF，只能作为附加预览。不得仅做摘要或漏页。
5. 网站中所有数学表达式用 LaTeX/KaTeX 正确渲染；代码要有语法高亮和可复制按钮；图表要解释坐标、变量、结论和可能误读。桌面和手机均可用，键盘可访问，不应出现横向溢出。
6. 网站需要：课程总览、先修诊断、依赖学习树、按周路线、知识点正文、作业索引、原始资料下载、中英精讲版下载、搜索、完成进度、节点笔记、问题清单、断点续学。进度/笔记/问题通过一个前端数据适配层保存；本地开发可回退 localStorage，生产环境使用相对路径 `/api/v1`，不要硬编码域名、IP 或密钥。
7. 这是四门课共享站的一部分。课程标识固定为：code=`PHY408`、slug=`phy408`、route=`/phy408/`。不要登录或修改共享服务器，不要改 Nginx、DNS、HTTPS、系统服务，也不要寻找其他项目中的账号密码。总控项目会统一部署。
8. 最终必须生成标准交付目录：`course-package/manifest.json`、`course-package/site/`（可直接由 Nginx 托管，含 index.html）、`course-package/source-coverage.json`、`course-package/README.md`。manifest 至少包含 schemaVersion、课程中英文名、code、slug、route、buildCommand、outputDir、apiBase、源文件数量、原始页数、翻译解释页数、作业数量、测试命令和构建时间。所有链接必须使用 `/phy408/` 基路径或相对路径。
9. 做严格验收：源文件覆盖率 100%；逐页映射无缺号；所有下载链接存在；公式无 KaTeX 错误；前端构建、类型检查、测试通过；对桌面与 390px 手机做可视化 QA；随机抽查至少 10% 原始页与翻译页；输出 SHA-256 清单。把“机械生成成功”和“内容质量通过”分开报告。
10. 可以并行使用子代理处理独立章节，但你必须统一术语、去重、交叉复核并最终验收。遇到材料歧义先依据课程上下文作合理标注，不要因为细小问题停工。只有确实需要我做决定、登录或提供缺失文件时才询问。

现在先扫描本项目全部材料并开始实现。持续工作到交付物可用，不要只回复建议或框架。
```

## 并行协作边界

- 三个课程项目都不要直接部署共享服务器，也不要编辑 DNS、Nginx、systemd 或数据库。
- 三个项目都不要把服务器 IP、SSH 私钥、访问令牌或任何账号密码写进源码、构建产物、日志或 Git。
- 每个项目交付 `course-package/` 后，把项目路径和 `manifest.json` 路径发回 PHY301 总控项目，由总控项目统一验证、合并、部署和回滚。
- 动态 API 使用相对地址 `/api/v1`；前端需要离线/本地回退，以免 API 暂不可用时影响阅读。
