先抓直觉

偏导是在多旋钮系统里只拧一个旋钮；下标告诉你其他旋钮被锁住。

小量展开、大 NNN 与最可能项

先抓直觉

统计物理不追踪 102310^{23}1023 个粒子；它利用“大数让分布尖锐”这一事实，把难求和化成找最大值附近。

ln⁡N!≈Nln⁡N−N∫dxeNf(x)由f(x)最大处x∗主导\ln N! \approx N \ln N - N\qquad \int dx e^{Nf(x)} \text{由} f(x) \text{最大处} x^{*} \text{主导}lnN!≈NlnN−N∫dxeNf(x)由f(x)最大处x∗主导

不是说其他项严格为零，而是相对贡献随 NNN 指数小。

展开精确定义与完整解释4 个认知动作
  1. 01

    Taylor 展开把复杂函数在某点附近写成多项式。临界点附近常保留 m2m^{2}m2、m4m^{4}m4；小时间演化常只保留 δt 的一阶项。

  2. 02

    Stirling 公式 ln⁡N!≈Nln⁡N−N\ln N!\approx N \ln N-NlnN!≈NlnN−N 把组合数的阶乘变成可微函数，是微正则计数和 Lagrange multiplier 的基础。

  3. 03

    若求和项形如 exp[Nf(x)] 且 NNN 很大，fff 最大处会压倒其他项。这就是 most probable 与 thermodynamic average 接近的原因。

  4. 04

    saddle-point/Laplace method 的最低阶做法：找 f′(x∗)=0f^{\prime}(x^{*})=0f′(x∗)=0，再检查 f′′(x∗)<0f^{\prime\prime}(x^{*})<0f′′(x∗)<0（最大）或对 e⁻ᴺᶠ 检查最小。
